# -----------------------------------------------------------------------------
# micro-wakeword-trainer dependencies
#
# The version pins below are load-bearing — they were validated against
# microWakeWord (OHF-Voice/micro-wake-word) and known-broken combinations:
#
#   * tensorflow 2.19+ ships a Keras whose `model.evaluate()` returns plain
#     numpy values; microWakeWord calls `.numpy()` on them and crashes.
#   * keras must stay < 3.11 for the same reason (3.8.0 is validated).
#   * datasets 4.x dropped soundfile-based audio decoding in favour of
#     torchcodec (pulls in all of PyTorch); 3.x decodes with soundfile/librosa.
#   * microwakeword must be installed EDITABLE (-e). Its setup.py uses
#     find_packages() but the `microwakeword/audio` and `microwakeword/layers`
#     subpackages have no __init__.py, so a regular install silently drops
#     them. An editable install maps the source tree and works.
#   * audio-metadata is installed from a fork that unpins `attrs` (the PyPI
#     release pins a version that conflicts with modern tooling). It must be
#     listed before microwakeword so the resolver picks the fork.
# -----------------------------------------------------------------------------
